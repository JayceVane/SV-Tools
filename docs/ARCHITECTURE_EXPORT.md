# 架构工程解析与报告导出规则

`design export` 用伪 SystemVerilog 确定模块、参数、端口和连接，用 `svtools.architecture.json` 读取标题、功能分组和讲解，再把两者组合成报告。架构查看器的「导出 HTML」和「导出 PDF」共用该导出逻辑。

## 1. 首页上的信息来自哪里

| HTML 中看到的内容 | 来源及规则 |
| --- | --- |
| 首页大标题 | 先查 `titles[顶层模块名]`。没有标题时显示实际顶层模块名。`--top` 选择解析哪个模块。 |
| 目录标题和单实例卡片标题 | 查 `titles[模块类型名]`。无配置时，章节用模块名，图中的实例卡片用实例名。实例类型和可求值参数由源码提供。 |
| 顶层功能块及其成员 | 查 `groups[父模块类型名][直接实例名]`。同一个父章内，填同一组名的实例在简图中折成一张卡，未分组的实例独立显示。功能组是图上的显示单位，章节仍按源码例化关系组织。 |
| 卡片位置、方位和连线绕行 | 由 ELK 和 SVTools 的布局规则确定。接口或普通信号如何接线、连线能确定的方向，取自结构模型。 |
| 快照统计 | 章节数按输出的结构模块页计，接口条目按各章的接口连接计。同一接口出现在不同章节时分别计数。待复核、实现桩输出和解析限制分别统计。 |
| 数据路径文字与时钟复位配对 | 来自 `walkthroughs[模块类型名]`。程序校验引用能否定位到本章接口或网络。 |
| 模块设计说明 | 来自 `designDocs[模块类型名]` 绑定的项目内 Markdown。作为章内说明显示，保留原文路径和文件指纹。 |

以 AI7100 报告为例，`--top architecture_top` 对应源码的 `module architecture_top`。大标题开头的「ai7100_top 顶层」来自 `titles.architecture_top`。简图里的四个功能组由 `groups.architecture_top` 指定。

| 顶层分组名 | 直接实例数 | 示例实例 |
| --- | ---: | --- |
| 时钟/复位与板级配置 | 3 | `u_clkrst`、`u_cfg` |
| PS 与 AI/存储 | 2 | `u_ps_ai`、`u_ai_ddr` |
| 内部总线桥（MNA） | 3 | `u_gp0_ch`、`u_gp1_ch`、`u_hp3_rd` |
| 视频与图像通路 | 7 | `u_gtx_sdi`、`u_frame_cap`、`u_pix_lane_pack` 等 |

例如 `groups.architecture_top.u_frame_cap` 决定 `u_frame_cap` 归入哪个功能组，`titles.frame_cap_ss` 决定它在哪里显示「抓拍子系统」。`u_frame_cap.img_out` 连到 `u_pix_lane_pack.axis`，是因为它们在 `rtl/architecture_top.sv` 都绑定到 `axis_video_if axis_cam()`。改标题或组名会改变展示。要改变这条连接，应修改伪 SV 例化绑定。

用同一份 AI7100 源码在独立副本中省略展示配置后，首页标题回退为 `architecture_top`，四张功能分组卡改为独立实例卡。报告仍生成 54 个模块章节和 192 个接口条目。

## 2. 工程解析

### 选文件和顶层

1. 以 `--workspace` 为根。指定 `--project` 时使用该工程。未指定时会发现 `.svtools/projects/` 中的 SVTools 工程配置和工作区中的 XPR 候选。CLI 的 `design export` 要求独立模型工程，若选择或发现 XPR 候选就提示改用模型目录。多个 SVTools 候选需要显式选工程。
2. 有工程配置时优先读所选文件集，缺省选设计文件集。无工程配置时递归收集 `.sv`、`.v`、`.svh`、`.vh`，跳过工具产物、依赖目录和扫描过程中的符号链接。配置的 include 目录和可解析的字面量 `` `include "..." `` 依赖也纳入源码快照。使用目录扫描时，模型目录中的旧副本也可能入选，重名声明会报错。
3. `--top` 必须命中模块声明。源码快照提供结构输入和出处。`.svtools/cli.json` 管通用 CLI 输入和工具配置，`svtools.architecture.json` 管报告展示。

### 从声明到实例和连线

| 源码内容 | 解析和投影规则 |
| --- | --- |
| `module`、`interface`、`package` | 收集结构声明及其源文件位置。模块及其直接例化构成报告层级。接口定义提供成员和 `modport`。空模块或合法位置的 `...` 保留端口，作为实现桩展示。 |
| `parameter`、`localparam`、例化参数覆盖 | 对支持的常量表达式求值，确定参数化端口宽度和结构身份。相同模块定义与求值参数复用一个章节。不同参数上下文可生成不同章节。 |
| 普通端口绑定 | 支持 `.port(net)`、`.port`、按声明顺序的位置绑定，以及能静态匹配的 `.*`。通过网络位建立端点关系。能静态确定的切片、拼接、重复和位宽对齐的连续赋值别名可参与连线。常量不会形成实例间网线。 |
| 接口束绑定 | 从本章的接口实例或接口边界端口取束名，收集绑定到该束且类型匹配的实例端口。成员的类型和位宽来自接口定义与可求值参数，方向来自每个端点的 `modport`。同一束有多个端点时保留其关系。 |
| 连线方向 | 把模块边界换算到模块内侧，普通输入在章内是信号来源，普通输出在章内是接收端。接口表仍保留原始 `modport` 声明方向。图上的束级主流向按证据产生，成员级方向可在详情复核。 |
| 时钟和复位 | 通过网络名或端口名识别常见 `clk`、`rst`、`reset` 等写法，用于简图标签分类。实际源端与接收关系取自结构模型。复位归属可由 `clockResets` 给出，命名规则本身不足以判断极性、同步方式或 CDC 安全性。 |

解析器对能确定的直接结构建模。遇到复杂 `generate`、无法确定的条件宏、动态表达式、多维或非打包数组、缺失模块定义或位宽无法求值时，相关对象可能保留为待确认，或在不确定连接处停止并记录诊断。过程块的时序、握手条件和功能结果需要结合实际 RTL 和验证核对。

若要单独核对结构，可以用 `design arch --engine struct --workspace <模型目录> --top <顶层>` 查看结构投影，再回到 HTML 查分组和可读说明。[结构分析入口](../src/design/struct.js) · [报告章节模型](../src/design/architecture-model.js) · [位级连接解析](../src/project/rtl-model.js)

## 3. 导出命令

CLI 的 `design export` 使用 `struct` 结构前端，需显式指定 `--workspace` 和 `--top`。

在 SVTools 仓库根目录运行以下命令。示例将 `architecture.html` 保存到 `example/struct-packet-hub` 工作区。

```powershell
node src/cli/main.js design export --workspace example/struct-packet-hub --top packet_hub --format html --out architecture.html
```

| 参数 | 规则 |
| --- | --- |
| `--format html\|pdf` | 默认 `html`。 |
| `--out <文件>` | 路径必须在输入工作区内，扩展名与格式一致。可创建父目录，已有文件会返回 `EEXIST`。 |
| 省略 `--out` | 生成 `.svtools/agent/architecture/<快照前12位>-<随机后缀>/architecture.<格式>`。查看器使用此规则。 |
| `--browser <exe>` | PDF 打印程序。查找顺序为显式参数、`SVTOOLS_PDF_BROWSER`、Windows 的 Edge 安装路径。 |

HTML 由 Node.js 生成。ELK 给出卡片和连线的位置，SVTools 渲染为 SVG，再把 SVG、CSS、脚本、分组图和接口预览一起嵌进单个 HTML 文件。浏览器打开报告后只负责呈现和交互，离线可用。

## 4. 章节与布局

1. 从顶层沿例化关系向下遍历。父章展示当前层的实例互联，子模块文档排在父章之后，使用 `1`、`1.1`、`1.1.1` 等层级编号。同一个结构模块首次遇到时建立章节，复用实例链接到该章节。实例参数仍按各自节点展示。
2. 顶层标题和快照统计位于页首。章节先展示职责或模块名，再展示可选的数据路径讲解、主图以及子模块入口。没有内部实例时，以模块端口图开场。接口、模块边界、时钟复位、普通信号和诊断按章收录，可按需展开。
3. 默认模式按章判断。直接实例超过 6 个、连接超过 18 条、图节点超过 14 个，或任一实例端口超过 14 个时，使用**简图**。其余有内部结构的章节使用**完整连线**。CLI 使用默认模式，查看器导出可沿用用户手动选定的章节模式。
4. 简图按配置折叠功能组、保留有名字的接口束，并可合并同一对模块之间的普通信号。首次布局宽度超过 1400 个 SVG 单位时尝试折行。完整连线绘制独立实例，并尽量落到具体引脚。
5. 模块边界的普通输入放左、普通输出放右。可识别的 `modport` 角色也用于接口端子分侧。接口束使用较粗蓝线，普通信号使用细灰线。箭头按结构证据表达方向，方向不足的连接使用虚线。端口名和位宽等标签在端子符号外侧显示。

## 5. HTML 交互

| 操作 | 输出规则 |
| --- | --- |
| 查章节 | 目录可展开、折叠和按模块名或职责搜索。筛选结果保留祖先章节。点实例卡片可进入对应模块，章节和接口可通过页内锚点定位。 |
| 查分组互联 | 点击分组的实例数或组内连接数，在点击点附近打开组内图。它从父章投影组内实例和相关连线，保留实际连接身份。只有组外驱动的多个组内接收端按外部网络处理。可切换原始尺寸，点弹窗外或按 Esc 收起。 |
| 查接口 | 在接口引脚上悬浮，预览成员、位宽和各端点声明方向。悬浮连线时高亮，点击接口或其连线可在图旁打开详情。实例名可定位子章节，端口声明、`modport` 和例化标明源码位置。 |
| 查时钟和复位 | 简图用同名标签和短引线连接，时钟和复位支持按同名网络联动高亮。短引线周围和端口标签行都可响应悬浮。章节的「时钟与复位」表列出按连接推导的源端与接收端。 |
| 读数据路径 | 章节有配置时，选步骤可高亮本章引用的接口。引用找不到或有歧义时显示「未定位」。 |

## 6. 展示配置

把 `svtools.architecture.json` 放在架构模型工作区根目录。以下片段适用于报文汇聚示例。

```json
{
  "titles": { "packet_hub": "四路采集与报文汇聚" },
  "groups": { "packet_hub": { "u_arbiter": "汇聚与缓冲", "u_fifo": "汇聚与缓冲" } },
  "walkthroughs": {
    "packet_hub": {
      "steps": [
        {
          "title": "从仲裁器送入 FIFO",
          "description": "打开接口详情，核对数据与 valid 的方向，以及 ready 的返回方向。",
          "links": ["arbitrated"]
        }
      ],
      "clockResets": { "clk": "rst_n" }
    }
  }
}
```

- `titles` 以模块类型名为键。`groups` 外层是父模块类型名，内层是该父模块的直接实例名。填同一个分组名的多个实例在简图中合并。
- `walkthroughs` 以模块类型名为键。步骤需要 `title` 和 `description`，`links` 填本章的接口连接名。关联的 `clockResets` 由作者提供，只有本章中能分别识别为时钟和复位的网络才显示。 [抓拍模块示例](../example/architecture-walkthroughs/frame_cap_ss.json)
- `designDocs` 以模块类型名为键，值是工作区内的 UTF-8 `.md` 文件相对路径，例如 `"designDocs": { "packet_fifo": "docs/packet_fifo/design.md" }`。报告和架构查看器可展开「模块设计说明」，PDF 打印正文。原始链接和图片以文字引用显示。绑定的文件参与快照校验，CLI 回执的 `data.designDocs` 列出模块、路径和 SHA-256。大小上限为单份 1 MiB、按输出章节合计 8 MiB。

## 7. 证据与输出格式

报告按 `modport` 声明展示接口成员方向，并从模块内侧换算边界端点的驱动关系。束级主流向可参考 `valid`、单一驱动端、端点角色或驱动位宽，详情会标出依据。复杂宏、生成分支、未知方向或多驱动以解析限制或待复核项呈现。实现桩的未驱动输出单独计数。报告表达源级结构，握手时序、背压、CDC 和复位行为应结合仿真及其他验证证据判断。

导出前和写入前会核对源快照与展示配置。HTML 页首显示结构快照的短标识，CLI 的 JSON 响应另有完整快照标识、源文件 SHA-256、章节数、接口数、诊断、产物路径、产物 SHA-256 和字节数。

| 需要的交付物 | 命令与差异 |
| --- | --- |
| 分层可交互文档 | `design export --format html`。单文件内保留目录、悬浮、分组互联和详情侧栏。 |
| 可打印分层文档 | `design export --format pdf`。以 A4 横向打印，展开端口、接口和时钟复位表，跨页表重复表头，讲解改为静态步骤，分组以简图显示。 |
| 独立架构图 | `design render --format svg\|png`。输出一张图，可以嵌入其他文档。伪 SV 的默认 `document` 接口视图采用 Block Design 布局和灰阶配色。 |
| 架构证据包 | `design report`。打包 SVG、PNG、`architecture.json`、`architecture.md` 和 `report.json`。 |

实现入口见[架构导出器](../src/design/architecture-export.js)。版式细节见[架构视觉规范](ARCHITECTURE_VISUAL.md)，CLI 参数见[架构 CLI](../skills/svtools-design/references/cli.md)。
