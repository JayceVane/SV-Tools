# SV Tools 4.2.0

本版把工程、架构、波形和交接串成一套可从终端调用、可在 IDE 查看证据的工作流。

- **Agent CLI 与 Skills**。用 JSON 查询工程、运行 Icarus 或 Vivado 任务、生成架构报告、检查波形。便携包包含 Windows 启动脚本和五个工作流 Skill。
- **架构和设计进展**。按稳定的需求与模块 ID 计划任务，支持领取、提交、退回及复验。工程侧栏新增只读进展，方便定位源码与证据。
- **VCD/FST**。支持层级筛选、查询、统计、CSV 和布局导出。按需在仿真后将 VCD 转为 FST，Icarus 可直接输出 FST。`wave glitches` 检查波形记录中的同刻变化。
- **电路与架构视图**。可选两端接口布局，表格接口放在普通端口外侧。
- **Vivado 证据**。工程输入、工具运行和结构化报告互相绑定。修改源码后，旧报告会标记过期。XSim 运行错误和断言失败会反映在任务状态中。

Windows x64 附件：

| 文件 | 用途 |
| --- | --- |
| `svtools-v4.2.0-win32-x64.vsix` | VS Code 或兼容 IDE 扩展 |
| `svtools-agent-v4.2.0-win32-x64.zip` | 终端 CLI 与 Skills，需要 Node.js 22 或 24 |
| `svtools-format.exe` | 独立格式化器，升级脚本时请更新旧 `svtools.exe` 路径 |
| `svtools.win32-x64-msvc.node` | 源码运行所用的同版原生模块 |
| `SHA256SUMS.txt` | 下载附件校验 |

Agent 首次运行 `svtools-agent.cmd doctor --workspace <RTL 工程目录>`。Icarus 和 Vivado 按需安装。波形核验以记录实际包含的信号和时间窗为限，功能结论仍应结合原始运行结果审阅。
