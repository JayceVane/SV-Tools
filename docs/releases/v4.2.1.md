# SV Tools 4.2.1

- Vivado 工程的文件视图新增默认折叠的 IP 和 Block Design 分组。工程标题显示所在目录，便于区分同名工程。
- xvlog 单文件检查根据正在编辑的源文件确定所属工程，并将工程成员所在目录纳入头文件搜索范围。
- SystemVerilog 和 Verilog 编辑器根据工程宏、源码及可解析的头文件淡化未选中的条件编译分支。编辑宏定义后自动更新高亮。

## Windows x64 下载

| 文件 | 用途 |
| --- | --- |
| `svtools-v4.2.1-win32-x64.vsix` | VS Code 或兼容 IDE 扩展 |
| `svtools-agent-v4.2.1-win32-x64.zip` | Agent CLI 和 Skills，使用 Node.js 22 或 24 |
| `svtools-format.exe` | 独立格式化器 |
| `svtools.win32-x64-msvc.node` | 供源码运行使用的原生模块 |
| `SHA256SUMS.txt` | 附件校验 |

安装后重载 VS Code 窗口即可查看新分组和条件分支高亮。
