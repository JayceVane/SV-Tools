# SV Tools 4.1.1

4.1系列修复版本，集中完善lint可靠性、源码索引和存储器电路展示。正式支持Windows x64，沿用4.1的设置与使用方式。

## 修复内容

- **检查停止与去重**：停止检查会同时撤销尚未启动的防抖；手动检查消费旧定时器，同版本自动保存复用正在进行的检查，避免重复启动和打断手动xelab。
- **配置变化隔离**：仅失效受影响的检查引擎，无关配置不再取消Icarus仿真；关闭全部自动检查后，配置变更不会额外启动lint。
- **依赖诊断刷新**：编辑依赖立即撤销相关旧诊断，保存后按自动检查配置重检；迟到结果不能重新覆盖新源码。当前文件模式过滤外部Problems，同时保留依赖失败、总错误数及日志入口。
- **源码索引**：采用最多8路异步读取、文件元数据缓存及共享刷新/重试链。保存与切换编辑器连续触发失效时先合并事件再重扫，修复Qoder中尚未编译就报“源码索引在扫描期间持续变化”的情况。
- **存储器电路**：依据Yosys读写时钟使能标注同步/异步模式；整个时钟端口明确未使用时隐藏该引脚及占位连线，属性保留说明。输出寄存器的真实时钟连接保持，未知、同步及混合端口保留。
- **追踪和导出**：局部追踪避免因无效存储器时钟留下孤立X节点；亮暗主题及SVG/PNG导出共用模式说明和引脚语义。

## 安装与验证

从本Release下载`svtools-v4.1.1-win32-x64.vsix`，或通过扩展市场升级，然后重载窗口。已打开的电路图重新打开即可应用新的展示规则。

扩展、原生模块和独立CLI统一为4.1.1；最低VS Code版本仍为1.106.0。Release同时提供`svtools.exe`、`svtools.win32-x64-msvc.node`和`SHA256SUMS.txt`。

修复基线完成805项公共回归、254项电路回归；12项需额外环境的公共检查默认跳过。正式VSIX在Qoder和VS Code完成38项验收，覆盖电路/Worker入口、内置Slang/Yosys、ELK、真实读时钟和模式展示；原生模块与CLI重新构建，并完成发布附件一致性检查。具体执行结果见对应提交CI和发布校验清单。

源码索引的3000文件双并发夹具，正文读取由6000次降为3000次，暖缓存为0；这是读取工作量，不代表所有工程的编译耗时提升比例。

## 范围

波形沿用VCD支持范围，FSDB保持不支持；静态分析未知项继续明确止步。4.2的CLI/Skill/MCP和Agent工程工作台处于独立规划阶段，不属于本版交付。
