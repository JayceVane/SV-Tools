# SV Tools 4.0.0

4.0首个正式版本。完整图文操作指南已同步到[GitHub Wiki](https://github.com/JayceVane/SV-Tools/wiki)。本轮通过GitHub Release分发Windows x64附件，历史3.x及所有预览版继续保留。

## 安装

下载 `svtools-v4.0.0-win32-x64.vsix`，在VS Code或兼容IDE执行“从VSIX安装”，随后重载窗口。最低VS Code1.106.0，兼容IDE需满足相同扩展宿主要求。VSIX自带原生格式化模块和离线Yosys，无需另装Rust、Python或Yosys；Icarus与Vivado按需安装。

`svtools.exe` 为独立CLI，`svtools.win32-x64-msvc.node`供源码运行使用；下载后与本Release的 `SHA256SUMS.txt` 核对。升级说明见[Wiki升级指南](https://github.com/JayceVane/SV-Tools/wiki/Upgrade-Guide)。

## 主要能力

- 格式化同时检查非布局字符顺序与词法边界；支持端口、例化、条件和task/function默认值列对齐，标量与向量共享名称列。UTF-8文件头可独立文件配置，内联模板使用多行控件。
- Verilog/SystemVerilog/UVM标准目录与上下文补全，提供作用域、类型、继承、数组、命名端口和参数等语义辅助；例化/Testbench保留原始接口信息，无法忠实生成时明确报错。
- Icarus/Vivado工具链与工程面板，任务可取消、日志有界缓存并完整落盘；跨文件集移动验证与回滚；重新仿真前释放旧VCD读取者。
- 后台流式VCD、A/B精确游标、浮点、二维mem、总线逐位展开、批量背景色、角色图标、分组排序和.svwave.json布局复用；已在公开合成数据上实测100/500MiB。
- 离线Yosys/Slang与Vivado适配的电路模型，ELK层级交互、源码定位、总线/分支位宽、寄存器语义、网络高亮和视口性能优化。
- 波形按A/B区间、电路按当前模块完整布局导出SVG/PNG，可选黑白技术文档风或当前主题。

## 验证与范围

沿用beta.16修复并以正式版本重新构建、回归和解包验收。此前基线包括golden44/44、Node666通过/1项可选跳过、电路170/170、Rust155/155及实际VS Code/Qoder验收。正式tag的CI重新执行原生/CLI构建、完整npm与Rust回归，实际附件哈希以本Release的清单为准。

本轮官方附件仅覆盖Windows x64。内置波形只支持VCD，不提供FSDB查看；二维mem取决于仿真器实际保留的索引与dump元素。补全不是完整编译器语义实现，电路是工具详细化/综合后的连接结果；Vivado电路为平坦RTL，独立IP新增/定制管理仍在后续计划。大文件和电路受容量预算约束，不能把单次性能测量视为所有工程的保证。
