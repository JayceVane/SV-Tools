# SV Tools 4.0.0-preview.1

这是基于 3.5.0 的首个 4.0 公开预览版，汇总 alpha1–alpha13 的开发成果。发布渠道为 GitHub Release，安装包仅针对 Windows x64；尚未发布到 VS Code Marketplace。

## 安装

下载 `svtools-v4.0.0-preview.1-win32-x64.vsix`，在 VS Code 扩展页执行“从 VSIX 安装”。VSIX 已包含当前平台原生模块，无需自行编译 Rust。独立 CLI 为 `svtools.exe`，另附 `.node` 模块和 `SHA256SUMS.txt` 校验清单。

## 本次变化

- 格式化器拆分词法扫描、结构状态和布局职责，修复 always 触发头及嵌套 if 条件紧凑。所有格式化入口强制保全 ASCII 空格、Tab、CR、LF 之外的字符及其顺序；不安全候选保留原文。
- 补全按 Verilog/SystemVerilog 版本及 UVM 1.2/1800.2 公开目录组织，增加作用域、成员、参数化类型和工程 include 索引。它仍是容错代码补全，不等同于完整编译器详细化。
- VCD 改用 Worker 流式解析和有界存储，按可见行与时间窗查询；支持二维 mem、双游标、精确边沿、分组、多选排序及可拖动栏宽/analog 行高。
- 显示格式归入子菜单，支持 FP64、FP32、TF32、BF16、FP16 和 IEEE 风格 FP8(E3M4)。明暗主题、值标签和紧凑菜单同步调整。
- 工具链统一任务取消、阶段成败和有界日志，避免失败后显示旧波形。修复 Vivado 空工程面板，统一工程选择、真实文件集与操作后验证。

## 验证与边界

发布构建通过 104 个 JS 文件语法检查、19 个 golden（38 断言）、510 项 Node 合同及 121 项 Rust 测试。此前使用真实 VS Code、Icarus、Vivado/XSim 和 100/500 MiB VCD 验证关键路径，详见仓库 `docs/V4_ALPHA*.md`。

500 MiB 生成 VCD 在本机热缓存下加载约 5.33 秒、RSS 峰值约 485 MiB；事件密度会影响资源用量，不保证任意同尺寸文件的表现。

已知限制：旧赋值对齐入口的正则异常会安全回退原文；GNU 风格与关闭行内紧凑的特定转换组合仍可能出现两轮缩进漂移。FSDB 已取消；Vivado IP 添加仍在后续计划。电路结构查看器属于下一版本，本安装包不包含该功能。其它平台及完整用户工程尚需进一步验收。
