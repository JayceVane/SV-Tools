# SV Tools 4.1.0

4.1正式版以信号追踪和电路/波形联动为主线，包含Open.28完成试用后的修复。通过GitHub Release分发Windows x64附件，历史4.0和预览版本继续保留。

## 安装与升级

下载`svtools-v4.1.0-win32-x64.vsix`，在VS Code或兼容IDE执行“从VSIX安装”，然后**重载窗口**。最低VS Code版本为1.106.0。扩展、原生模块与CLI均为4.1.0；VSIX自带原生格式化模块、离线Yosys/Slang及ELK资源，Icarus和Vivado按需安装。

独立CLI为`svtools.exe`，源码运行可使用同版`svtools.win32-x64-msvc.node`。请使用本Release的`SHA256SUMS.txt`核对附件。原有常用设置继续使用；升级后重新生成电路、重新打开VCD，再确认双方实例映射。

## 新增与完善

- **源码和电路信号追踪**：按真实实例和位范围查询驱动/负载，逐级展开局部逻辑锥，明确时序及未知语义边界；支持前进/返回、固定关注、显式跨时序和经过快照校验的源码定位。
- **统一工程侧边栏**：单一面板切换Vivado及SV Tools工程；从资源管理器右键添加文件/目录。所选信号的走向在文件和实例右侧标注，支持多层级透传、总线重排和仿真TB追踪根。默认选择即追踪，可改为手动；静态工程分析无需Yosys。
- **电路与VCD联动**：人工确认DUT实例映射后可双向定位、从波形反查驱动/负载，在电路观察A/B精确值和变化位。源码、视图或仿真变化使旧关联失效。
- **EDA电路绘制**：标准标量门、MUX、时序极性、统一引脚、真实junction、总线粗线和斜杠位宽；加入小地图、可折叠属性、驱动/负载高亮和窄窗口适配。
- **波形调试与图片复制**：全程时间轨道和视窗滑块；源码稳定后自动恢复方向图标并保留查看状态。电路和波形均可导出SVG/PNG或复制PNG；Windows剪贴板直接使用原生接口。
- **仿真及任务目录**：Icarus本轮VCD统一归档到`.svtools/vcd`，保持源码cwd和相对readmem。Vivado流程集中提供综合、实现、Bitstream及报告。任务默认保留最近5轮已交还记录，活动任务及仍被使用的快照保留。
- **稳定性修复**：修复追踪来源失效、观察重绑、分支展开、非UTF-8可选快照、工程目录移出、菜单重复点击和导出覆盖边界，保留格式化字符顺序及词法安全约束。

## 验证与范围

Open.28试用基线通过783项公共检查、247项电路检查及44项golden断言；12项需额外环境的检查默认跳过。此前已完成VS Code/Qoder实际宿主、真实Icarus、100/500MiB VCD和复杂电路交互验收；单次测量不能保证所有工程的性能。正式版本重新构建原生模块和CLI，PR CI覆盖Node22/24与Rust，发布工作流从正式tag重新构建附件并生成实际SHA256清单。

公开版不提供ModelSim/Questa专用工具链或私有覆盖率功能。内置波形只支持VCD，不支持FSDB。静态工程追踪对无法解析的宏、生成分支、用户类型或复杂表达式明确止步；综合电路与源码并非逐语句一一对应。VCD关联需要匹配实例、声明范围和实际dump数据，人工映射不等于验证来自同次构建。Vivado电路沿用平坦RTL适配；独立IP管理仍在后续计划。
