# 架构查看器

在 VS Code 中执行「SV Tools: 打开架构查看器」。查看器沿用当前工程的设计文件集和顶层设置，工作区没有配置顶层时会提示选择。它读取已保存的 SystemVerilog／Verilog 源码，也支持结构设计里的空模块和 `...` 实现占位符。视觉规范见 [架构输出的视觉规范](ARCHITECTURE_VISUAL.md)。

- **简图**按模块和接口束组织连接。同一对功能块之间合并成一条线，点击后可展开相关连接。时钟和复位以同名标签显示，在「标签网络」可查全部端点。
- **完整连线**展开独立实例，连线接到可解析的具体引脚。每层根据实例、端口和连线数量选择默认视图。小型结构默认展示完整连线，复杂结构默认展示与顶层相同的简图。两种视图可以手动切换。
- **边界端口排**把同一方向的模块边界端口收成一条灰色"端口条"：标题写着 `模块边界`，左侧是输入端口与接口束，右侧是输出端口；每一行是一个真实端口，带方向字形、位宽或接口类型。端口条与实例卡片在配色和内缘脊线上刻意区分，不会被误读成子模块；每一行各自连到它实际归属的实例或分组，不做整排合并。边界端口不超过两个时保留单个旗标符号。
- **连线编码**：接口束用较粗的蓝线，普通信号用细灰线；已知方向在端点画箭头，双向两端都有箭头，方向待确认用虚线且不画箭头。连线标签带底色并自动避让，放不下时省略，不会互相压盖。
- **实例卡片**按"标题带 → 实例名与类型 → 端口 → 共享网络脚注"组织。标题最多两行，不会截成无意义的省略号；实现桩和未解析模块在卡片右上角标注，虚线边框表示实现尚未确认。
- **模块端口图**是数据手册式器件符号：输入在左、接口束居中、输出在右，分组标题带数量；普通引脚按 20px 行高排列，位宽紧跟名称，输入 `→`、输出 `→`（朝外）、双向 `◆`、引用 `-○`。接口束每束一行，含总线字形、接口类型、modport 与 Master／Slave 芯片，未声明 modport 显示 `—`。窄容器自动改为单列堆叠。
- **选中模块**时突出直接上游、下游和方向未确认的共享连接。需要逐项核对时可展开端口明细表。模块内部的寄存器与组合逻辑由源码解释。
- **点击接口**查看具体成员。工具根据两端的 `modport` 判定 `valid` 正向和 `ready` 反向，并列出成员位宽、端点声明与例化。边界接口以模块内侧为观察视角。全接口、条件声明和多驱动等不确定情况会保留待确认提示。
- **导出 HTML／PDF**按顶层到子模块的顺序生成章节和目录，包含各模块的端口图。页首给出统计条，章节导航支持筛选，图下有编号图注，复核项与接口详情单独成节。图内链接可进入子模块及单独的接口说明。PDF 使用 Edge 或通过 `SVTOOLS_PDF_BROWSER` 指定的 Chromium，两种格式保存在工程的 `.svtools/agent/architecture/`。

可以在根目录放置 `svtools.architecture.json`。`titles` 以模块类型名为键，`groups` 以父模块名为键，为其直接实例指定功能块名称。查看器以源码为连接依据，配置仅供章节命名和简图排版。[四路采集与报文汇聚示例](../example/struct-packet-hub/README.md)

Agent 可在单独的伪 SystemVerilog 工作区用 `design export --workspace <目录> --top <模块> --format html|pdf --out <文件>` 生成同样的分层文档。[架构 CLI](../skills/svtools-design/references/cli.md)

导出的 HTML 支持筛选章节、展开接口或端口明细，并可按原始尺寸查看复杂架构图。报告开头的复核索引跳转到涉及的章节，实现桩输出单独计数。PDF 展开接口和端口表，按内容分页并重复跨页表头。

修改渲染代码后先用 `node scripts/preview-architecture.js --workspace <伪SV目录> --top <top> --page <模块> --mode overview|detailed --out <png>` 出图核对，再跑架构相关测试。

架构是源级连接快照。它会标出空实现和静态诊断；复杂宏、生成分支和动态连接需要结合编译结果。握手时序、背压期间的数据稳定性、CDC 和复位语义仍需要用仿真或其他验证方法核对。
