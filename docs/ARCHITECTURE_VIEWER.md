# 架构查看器

在 VS Code 中执行「SV Tools: 打开架构查看器」。查看器沿用当前工程的设计文件集和顶层设置，工作区没有配置顶层时会提示选择。它读取已保存的 SystemVerilog／Verilog 源码，也支持结构设计里的空模块和 `...` 实现占位符。视觉规范见 [架构输出的视觉规范](ARCHITECTURE_VISUAL.md)。

- **简图**按模块和接口束组织连接，每条接口束落在独立的具名端口上，同一对功能块之间的普通信号可合并。点击连线可展开相关连接。时钟和复位以带 `CLK`／`RST` 标记的同名标签显示，只承担这类连接的模块集中在图下方。悬浮标签查看源端和接收端，选中模块可追踪关联端点，在「标签网络」可查完整连接。
- **完整连线**展开独立实例，连线接到可解析的具体引脚。每层根据实例、端口和连线数量选择默认视图。小型结构默认展示完整连线，复杂结构默认展示与顶层相同的简图。两种视图可以手动切换。
- **超宽简图**自动按通路折成多行，跨行连线保持接口名称和箭头，卡片、端口及字号沿用同一套样式。查看器与导出报告共用布局规则。
- **边界端口**以独立端子排列，名称和类型写在符号外侧。普通输入放左侧、输出放右侧，接口束根据声明的 `modport` 角色放置，Master／source 类在右侧，Slave／sink 类在左侧。每个端子有自己的接线落点。
- **连线编码**：接口束用较粗的蓝线，普通信号用细灰线；已知方向在端点画箭头，双向两端都有箭头，方向待确认用虚线且不画箭头。连线标签带底色并自动避让，放不下时省略，不会互相压盖。
- **实例卡片**与功能分组共用标题带、外框和端口样式。单个实例显示实例名与类型，分组显示成员数量和组内连接条数；点卡片脚注可展开同名同色的组内连接清单（接口束蓝、信号灰），再点收起。简图中的长标题可换成三行，端口按左右两列排列。实现桩和未解析模块带状态标注，虚线边框表示实现尚未确认。
- **模块端口图**采用 Block Design 的左右两侧布局。输入与 Slave／sink 类接口在左，输出与 Master／source 类接口在右，分组标题带数量。普通引脚按 20px 行高排列，位宽紧跟名称，双向端口使用 `◆`。接口束含总线字形、接口类型、modport 与 Master／Slave 标记，未声明 modport 显示 `—`。窄容器自动改为单列堆叠。
- **选中模块**时突出直接上游、下游和方向未确认的共享连接。需要逐项核对时可展开端口明细表。模块内部的寄存器与组合逻辑由源码解释。
- **点击接口**查看具体成员。工具根据两端的 `modport` 判定 `valid` 正向和 `ready` 反向，并列出成员位宽、端点声明与例化。边界接口以模块内侧为观察视角。全接口、条件声明和多驱动等不确定情况会保留待确认提示。
- **接口悬浮预览**在图内接口、连线及模块端口图上显示成员表，含位宽和各端点的 modport 声明方向。指向具体端口时只显示该端口的方向，指向接口连线时并排显示各端点。长表可滚动，支持键盘焦点预览和 Esc 关闭，HTML 与编辑器共用预览逻辑。
- **模块章节**按照父子层级编号，例如 `1.3`、`1.3.1`。父章展示本层互联及子实例索引，子模块文档嵌入子章节；复用同一模块定义时链接至同一章节。查看器目录、面包屑与 HTML 目录保持相同层级，筛选子模块时保留其祖先条目。
- **导出 HTML／PDF**包含各模块的端口图。页首给出统计条，章节导航支持筛选，图下有编号图注，复核项与接口详情单独成节。图内链接可进入子模块及单独的接口说明。PDF 使用 Edge 或通过 `SVTOOLS_PDF_BROWSER` 指定的 Chromium，两种格式保存在工程的 `.svtools/agent/architecture/`。
- **独立 SVG／PNG**通过 `design render/report` 输出。伪 SV 的默认 `document` 架构图复用查看器的 Block Design 布局，但配色强制灰阶（R=G=B，接口束按线宽区分），保留结构快照证据与图像哈希，适合独立插入文档；HTML／PDF 报告仍是彩色。

可以在根目录放置 `svtools.architecture.json`。`titles` 以模块类型名为键，`groups` 以父模块名为键，为其直接实例指定功能块名称。查看器以源码为连接依据，配置仅供章节命名和简图排版。[四路采集与报文汇聚示例](../example/struct-packet-hub/README.md)

Agent 可在单独的伪 SystemVerilog 工作区用 `design export --workspace <目录> --top <模块> --format html|pdf --out <文件>` 生成同样的分层文档。[架构 CLI](../skills/svtools-design/references/cli.md)

导出的 HTML 支持筛选章节、展开接口或端口明细，并可按原始尺寸查看复杂架构图。报告开头的复核索引跳转到涉及的章节，实现桩输出单独计数。PDF 展开接口和端口表，按内容分页并重复跨页表头。

修改渲染代码后先用 `node scripts/preview-architecture.js --workspace <伪SV目录> --top <top> --page <模块> --mode overview|detailed --out <png>` 出图核对，再跑架构相关测试。

架构是源级连接快照。它会标出空实现和静态诊断；复杂宏、生成分支和动态连接需要结合编译结果。握手时序、背压期间的数据稳定性、CDC 和复位语义仍需要用仿真或其他验证方法核对。
