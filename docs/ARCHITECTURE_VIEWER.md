# 架构查看器

在 VS Code 中执行「SV Tools: 打开架构查看器」。查看器沿用当前工程的设计文件集和顶层设置，工作区没有配置顶层时会提示选择。它读取已保存的 SystemVerilog／Verilog 源码，也支持结构设计里的空模块和 `...` 实现占位符。

- **简图**按模块和接口束组织连接。同一对功能块之间合并成一条线，点击后可展开相关连接。时钟和复位以同名标签显示，在「标签网络」可查全部端点。
- **完整连线**展开独立实例，连线接到可解析的具体引脚。每层根据实例、端口和连线数量选择默认视图。小型结构默认展示完整连线，复杂结构默认展示与顶层相同的简图。两种视图可以手动切换。
- **模块端口图**把输入放在左侧、输出和双向端口放在右侧，双向引脚用 `↔` 标记。接口束在宽图中排在中间，在窄图中排在两侧引脚上方。每个总线端子带端口名、接口类型和 `modport`，Master 与 Slave 用不同颜色和文字标签区分。点开接口束可查看成员方向，点击普通引脚可查看连接与源码声明。叶子模块直接显示端口图；有内部结构的模块可从实例继续展开，参数化实例会打开对应参数的章节。
- **选中模块**时突出直接上游、下游和方向未确认的共享连接。需要逐项核对时可展开端口明细表。模块内部的寄存器与组合逻辑由源码解释。
- **点击接口**查看具体成员。工具根据两端的 `modport` 判定 `valid` 正向和 `ready` 反向，并列出成员位宽、端点声明与例化。边界接口以模块内侧为观察视角。全接口、条件声明和多驱动等不确定情况会保留待确认提示。
- **导出 HTML／PDF**按顶层到子模块的顺序生成章节和目录，包含各模块的端口图。图内链接可进入子模块及单独的接口说明。PDF 使用 Edge 或通过 `SVTOOLS_PDF_BROWSER` 指定的 Chromium，两种格式保存在工程的 `.svtools/agent/architecture/`。

可以在根目录放置 `svtools.architecture.json`。`titles` 以模块类型名为键，`groups` 以父模块名为键，为其直接实例指定功能块名称。查看器以源码为连接依据，配置仅供章节命名和简图排版。[四路采集与报文汇聚示例](../example/struct-packet-hub/README.md)

Agent 可在单独的伪 SystemVerilog 工作区用 `design export --workspace <目录> --top <模块> --format html|pdf --out <文件>` 生成同样的分层文档。[架构 CLI](../skills/svtools-design/references/cli.md)

导出的 HTML 支持筛选章节、展开接口或端口明细，并可按原始尺寸查看复杂架构图。报告开头的复核索引跳转到涉及的章节，实现桩输出单独计数。PDF 展开接口和端口表，按内容分页并重复跨页表头。

架构是源级连接快照。它会标出空实现和静态诊断；复杂宏、生成分支和动态连接需要结合编译结果。握手时序、背压期间的数据稳定性、CDC 和复位语义仍需要用仿真或其他验证方法核对。
