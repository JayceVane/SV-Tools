# 架构输出的视觉规范（4.3 前端打磨）

本文件是架构文档、查看器和独立 SVG 渲染的共同视觉契约。修改渲染代码时先对照这里，
再按 `scripts/preview-architecture.js` 的方式出图核对，避免只靠文字判断美观。

## 1. 目标与原则

架构图是**工程图纸**，不是仪表盘。阅读顺序优先于装饰：

1. 一屏能读出"有哪些块、谁连谁、走的是什么总线"；标签不得互相压盖，不得被卡片遮挡。
2. 层次稳定：模块标题 > 实例名 > 端口名 > 连线标签；字号差 ≥1px，靠字重和颜色区分次要信息。
3. 颜色只承载语义：接口束（总线）用蓝，普通信号用中性灰，未知方向用虚线，错误/未解析才用暖色。
4. 一切尺寸走 4px 栅格；卡片、端口、行高统一节奏，避免大小混杂。
5. 不给信息量低的元素留大块空白：空卡片、悬空端子、重复截断的省略号都要消除。
6. 中文与等宽标识混排：中文走 UI 字体，模块名/端口名/位宽走等宽字体。

## 3. 架构连线图（`architecture-diagram.js` + `architecture-diagram.css`）

### 3.1 画布

- 背景 `--panel`，无网格、无渐变。
- 图外留白 ≥ 16px；详细连线卡片的间距 ≥ 24px、层间距 ≥ 56px。
- 简图目标宽度 ≤ 1400px，层间距 42px，节点间距 16px。串行通路超过目标宽度时，使用布局引擎的多边折行重排，跨行连接保留箭头。字号与卡片绘制规则保持统一。
- 连线端点落在卡片主体侧边。简图为不同接口提供独立的具名落点，详细连线使用逐引脚锚点。
- 简图以同名标签呈现时钟和复位，只接这类网络的模块排在下方功能区域。标签带 `CLK`／`RST` 标记，保留网络身份、两端短线和方向，悬浮可查源端和接收端；详细连线呈现端到端路径。

### 3.2 实例卡片

结构（自上而下）：

1. **标题带**：高 34px，底色 `--sunk`，底边 1px `--line`。标题 12.5px/600 `--ink`，左侧内缩 12px。
   简图标题最多三行，详细连线通常最多两行，超长按词换行并保留悬停全文。
2. **副标题行**：等宽 10.5px `--muted`，左边是实例名，右边（右对齐）是模块类型 chip：
   等宽 9.5px、底色 `--sunk-2`、1px `--line`、圆角 3px、内边距 2px 5px。
   未解析/实现桩用同位置的状态 chip：`桩`（`--muted`）或 `未解析`（`--warn`，虚边框）。
3. **主体**：单行距 2px 内边距。
   - 单个实例：主体只放端口；无端口时高度压到标题+副标题（不留空白）。
   - 分组卡片（简图）沿用同一标题带和外框，副标题显示成员数量，主体按 22px 行高排列对外端口，脚注保留组内接口索引。
4. **共享网络脚注**（仅有 `card.labels` 时）：高 20px，上边 1px `--line`，文案
   `≡ gp_clk · hp_clk · ai_rst_n +6`，10px `--muted`，单行省略；最多 3 个名字后接 `+N`。

卡片本体：1px `--line-2` 描边、圆角 `--radius-2`、`--panel` 填充；未解析用 1px 虚线 `--warn`；
实现桩用 1px 虚线 `--line-2`。不加阴影。

### 3.3 引脚

- 行距 18px；标量引脚：外伸 6px 短线 + 3px 圆点（`--wire` 描边、`--panel` 填充）。
- 接口束引脚：外伸 6px 短线 + 8×8 的"总线端"图形（两条横线 + 右侧竖线，`--bus`），
  标签前加 `≡` 前缀，颜色 `--bus`，与标量引脚一眼可分。
- 标签：等宽 10.5px；西侧左对齐内缩 12px，东侧右对齐内缩 12px；不出现省略号（按需加宽卡片）。
- 输入/输出不再重复画方向三角，方向由所在边表达；`inout` 用实心菱形端头。

### 3.4 边界端口排（pad）

边界端口逐行呈现为终端符号与外侧名称。

- 名称使用等宽 10.5px，位宽或接口类型使用 9.5px `--faint`。行高 18px，端子尺寸 20×12px。
- 普通输入放左侧，输出放右侧。接口束按已有 `modport` 角色词表分置两侧，Master／source 类朝右，Slave／sink 类朝左，箭头沿用结构模型中的方向证据。
- 每条端口行连到真实实例或分组，连线从终端符号边缘出发。
- 普通信号使用五边形，接口束使用矩形，并沿用 Block Design 的终端符号实现。

### 3.5 连线与标签

- 正交折线，拐角 4px 圆角（`Q` 二次曲线），线端与引脚/端子对齐，不伸入卡片。
- 普通信号：1.1px `--wire`；接口束：2.2px `--bus`。
- 已知方向：`marker-end` 小三角（6×6，同色）；双向：两端都加；未知方向：虚线 `4 3`，无箭头，
  颜色仍用 `--wire`（不得使用紫色等第三种强调色）。
- 标签 chip：圆角 2px、`--panel` 填充、1px `--line` 描边、等宽 10px `--ink-2`、内边距 2px 4px。
  优先放在最长的水平段中点；必须做避让：标签之间、标签与卡片不得重叠；
  放不下时依次尝试其它水平段，仍放不下则省略该标签（可读性优先）。
- 两端同名（端口排行名 = 目标引脚名）时不画标签，避免同一名称在一行里出现三次。
- 方向字形按"数据流"约定：左侧端口排 →（流入图面），右侧端口排 →（流出图面），
  双向 ◆，接口束用 ≡ 总线字形。
- 标签冲突时不允许缩小字号，也不允许旋转 90°。

### 3.6 图例与交互

- 查看器图例保持"上游 / 下游 / 共享·待确认"三项 + 操作提示，一行 12px。
- 保留 `data-node`、`data-edge`、`data-link`、`.edge-hit`、`.architecture-svg`、
  `[data-state=dimmed|selected|upstream|downstream|related|both]` 契约，
  选中态用 2px `--up/--down` 描边 + `--panel` 遮罩变淡，不做发光。
- 接口引脚与单束连线通过 `data-preview-link` 关联表格预览；具体引脚额外保留节点与端口身份。
  预览展示成员、位宽及 modport 声明方向，宽度 ≤ 640px、高度 ≤ 430px，限制在视口内，长表滚动。

## 4. 模块端口图（`architecture-details.js` + `architecture-symbol.css`）

一张 Block Design 模块边界符号，宽度随内容、居中，最大占满内容区：

- 外框：`--panel` 填充、1px `--line-2`、圆角 `--radius-2`。
- 标题带：高 30px、`--sunk`、底部 1px `--line`；模块名等宽 12px/600 居中。
- 主体左右两侧：输入与 Slave／sink 类接口在左，输出与 Master／source 类接口在右。
  接口束位于各侧普通引脚之前，不另建中间接口栏。
  分组标题 10px 加宽字距、`--muted`、大写；分组计数跟在标题后（`--faint`）。
- 普通引脚一行：高 20px；外侧 8px 短线 + 端头（输入 `▸`、输出 `◂`、双向 `◆`），
  名称等宽 11.5px，位宽 `[16]` 9.5px `--faint`；整行可点击不显示边框，悬停底色 `--sunk`。
- 接口束一行：总线字形（12×10，`≡` 风格，Master `--bus`、Slave `--down`）+ 等宽名称 +
  次行类型（`axi_hp_if`）与 modport，角色标记 `Master`/`Slave` 9.5px 圆角 2px；
  无 modport 时显示 `—` 而不是空白。行间 1px `--line`，整行可点击。
- 窄容器（`@container (max-width: 360px)`）降级为单列，按左侧、右侧依次堆叠。
- 双向端口在输出侧使用菱形标明；引用和待确认端口置于底部共享栏。

## 5. 报告外壳（`architecture.css` + `architecture-book.css` + `architecture-export.js`）

- 页首：眉标 `架构设计 · ARCHITECTURE`（11px 字距 0.12em `--muted`）→ h1 26px/600 → 等宽元信息行
  （`architecture_top · 结构快照 2500e1837e6a`）→ 统计条：4 个统计项，数值 19px/600、标签 11px `--muted`，
  项目之间 1px `--line` 竖线分隔，不要圆点列表。
- 侧栏：标题"模块章节"11px 大写；筛选框高 28px；章节条目：序号等宽 10px `--faint` + 标题 12px +
  模块名等宽 10.5px `--muted`；当前项左侧 2px `--accent` 竖条 + `--sunk` 底。
- 子模块文档嵌入父章下的子章节，目录按层级缩进，序号 `1`、`1.1`、`1.1.1`；复用模块以链接引用。
- 章节头：眉标行显示序号与返回父章链接；序号等宽 11px `--accent`；模块标题 19px/600；
  模块职责 13px `--ink-2`；源码链接等宽 11px `--muted`。
- 小节标题：11px 加宽字距大写 `--muted` + 底部 1px `--line`（如 `模块端口图` / `子模块` / `接口目录`）。
- 图外壳：1px `--line`、圆角 `--radius-2`、内留白 12px，右上角"原始尺寸"按钮；图下方图注
  `图 1 · 结构连线（简图/完整连线）` 11px `--faint`。
- 表格：表头 11px 大写 `--muted`、`--sunk` 底、底部 1px `--line-2`；单元格 12px、行高 26px、
  行间 1px `--line`；等宽列用 `--font-mono`；数字右对齐。
- 待复核提示：左侧 2px `--warn` 竖条 + `--sunk` 底，标题 12px/600，列表 11.5px。
- 打印（PDF）：A4 横向、8.5pt 正文、每章从新页开始、表格跨页重复表头、图最大高 120mm、
  页脚显示章节名与页码。

## 6. 独立 SVG（`architecture-image.js` / `svg.js`，`design render/report`）

- 结构解析器（`struct`）的默认 `document` 接口图共用第 3 节的 Block Design 渲染器、布局和配色，
  SVG 内解析主题令牌，保证浏览器和 PNG 栅格化结果一致。叶子模块同样绘制左右端口的模块符号。
- 信号级展开、折叠边界、束聚合及 Yosys 投影沿用 `svg.js` 的明细渲染规则，`document` 主题为灰阶。
- 以下约束适用于 `svg.js` 的明细渲染：
- 实例盒：44px 标题带（浅灰）→ 13px 标题 → 11px 模块类型 → 右上角实现状态 chip；
  端口标签与标题带同宽排布，接口束端口画总线端头 `≡`。
- 边界接口表：表头 10px 大写、行高 22px、方向列与位宽列右对齐、行间 0.5px 细线。
- 连线：正交圆角 4px；总线 1.8px、信号 1.0px；标签 chip 用 `paint-order` 白描边保证可读。
- 保留：`<metadata id="svtools-evidence">`、`data-model-id` 数量、`stroke-dasharray="6 4"/"2 3"`、
  `(N bits)` 标签、`signals:` title、图例四项与窄图换行。

## 7. 验收

1. `node scripts/check-js.js`
2. `node --test test/architecture_viewer_test.js test/design_render_test.js test/design_report_test.js`
3. `node scripts/preview-architecture.js --workspace <伪SV目录> --top <top> --page <模块> --mode <overview|detailed> --out <png>`
   出图核对：无重叠标签、无悬空端子、无大片空白、标题不被截断成无意义省略号。
4. 导出整本 HTML：`node src/cli/main.js design export --workspace <目录> --top <top> --format html --out <文件>`，
   检查章节导航、端口图、接口表与打印分页。
