# 单 bit packed 范围与数组地址混淆

显式 `$var wire 1 ! bus [3:3] $end` 原先只生成显示名称 `bus[3]`，与真正
unpacked 元素 `bus[3]` 无法区分。存储器归并会将该 bus bit 当作数组地址；一位
`mem[2] [0:0]` 也会被误认成两层数组。width=1 分支还未记录已经见过范围，
因此可能接受重复 packed 范围或范围之后的数组索引。

解析器保留历史 name/path，并在单 bit packed 选择上增加 `referenceName`，表示
附加显示用 bit 索引之前的引用。存储器归并优先用该字段；独立 `hasRange` 状态
约束范围只能出现一次且处于数组索引之后。多位 range 的显示与事件查询继续兼容。

合同覆盖 packed bus 不归并、一位 mem 仍按 word 查看、重复范围拒绝以及原名称保留。
仅有单整数索引且没有 packed 范围的 VCD 仍缺少源码类型事实，不能单靠 VCD 判定其声明类型。

Questa 逐位 dump 的向量也会使用这种形式，且可能重复发出同一组声明。查看器现在结合
工作区 RTL：只有精确匹配的声明没有 unpacked 维度、索引连续且顺序一致时才恢复为总线；
同下标同 ID 的重复声明去重，同下标不同 ID、索引空洞、缺源码时保留原声明。真正的
`reg mem[addr]` 不参与归并。`source-roles.js` 提供声明事实，`packed-buses.js` 负责归并，
`composite-events.js` 只建立联合时间索引，数值和位边沿复用原始标量存储。方向上下文稍后
恢复时也可完成归并；已有自动保存的逐位行映射回父总线。

手动拆分通过原始总线的绝对位偏移表达，再次拆分替换该段并保持同层，不能以子段偏移
再次投影已投影的绘图值。A/B 读值、绘图、边沿及可移植布局均复用同一切片身份。

回归位置：`test/waveform_signal_test.js`，包括逐位/重复声明、真实 bit mem、同 ID 别名、
X/Z、切片再拆分、升降序、负下标、输入校验、保存恢复和切片边沿续查；
`test/waveform_renderer_test.js` 验证切片标签与游标值没有二次移位。
