# logic-wave-probe-reselection

> **发现方式**：4.1严重缺陷排查。
> **修复位置**：`src/debug/cursor-values.js` / `watch`。
> **修复提交**：`fa0ecaaa196d1dc24c74002f5ffaae157281a652`。

## 症状

VCD有同路径、同范围但identifier code不同的候选声明时，用户重新选择另一条声明，界面仍读取第一次选定的事件源。
先登记`v=0011`，再为同一电路起点明确选择`other=1110`，回归实际结果：

```text
"4'h3" !== "4'hE"
```

## 根因

观察去重以电路实例、对象和选定位为键。复用旧观察项时只更新了画布锚点和视图世代，没有更新`query.id`及投影offsets。人工选择新VCD声明的操作被去重逻辑悄悄丢弃。

## 修复

每次观察都先从当前选定声明构造查询投影，复用探针ID时一并替换查询。原有查询世代递增和A/B成组发布继续拒绝迟到旧结果，不新增第二条名称相同的观察行。

## 教训

对象身份相同不代表数据来源不变；凡允许重新选择候选，去重分支必须更新用户重新确认的绑定内容。
