# logic-circuit-bus-labels

> **发现方式**：用户要求区分多比特总线与单比特信号；真实Slang/ELK页面验收发现两个相邻问题。
> **修复位置**：src/circuit/renderer.js、viewport.js、projection.js及view.css。

## 症状与排查

原线型只有1.3px/2px，选中后均为2.7px，没有直观位宽。新增标记后，真实32位数据电路的输入线没有标记，而输出切片的8和24标记重叠。

检查原始路由发现输入线端点y分别393.8和393.80000000000007，精确等号把它误判为斜线；输出低8位分支和高24位路由确实共享同一条折线，按各自长段中点放数字必然重合。另有ELK冗余共线折点会把足够长的直线分成多条短段，导致漏标。

## 修复

几何层以1e-6容差识别近似正交段，仅规范化同向共线折点而不改写工具路由。优先水平长段，候选包括中点及空间充足时的四分点。稀疏网格预留单元/标题和既有标签空间，冲突时换位置或另一个段，无法安全放置则保留粗线及详情位宽。

renderer与裁剪索引复用同一标记Map，避免显示位置与可见范围不一致。注释几何包含位宽文本的外侧空间，防止高倍率下连线中心已在屏外、可见文字却被提前移除。极大非安全网格坐标不进入逐格循环。

位宽来自连线/端口自身bits长度。32位端口的两组路由可以分别为8和24，不把父端口总宽度写到每条切片上。单比特常量驱动多位重复常量端口时，路由仍可为单比特；引脚保留自己的多比特身份。

## 验证

新增7项回归覆盖位数分类、标记点击、端口空间、虚拟化恢复、8倍缩放裁剪、短线/错误折点、浮点段和重合标签。真实Slang/Yosys生成10节点/12连线、位宽1/8/24/32电路，浅深主题、选中粗细、标签不覆盖单元或彼此、紧凑/总览状态通过。2000节点/5994条32位连线的同机前后基准见../V4_1_ALPHA9.md。
