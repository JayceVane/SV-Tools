# 4.1 M2：源码追踪与局部电路

日期：2026-10-25。分支：`codex/feat-v4.1-signal-tracing`。前置交付：[M1查询层](V4_1_M1.md)。当前扩展、native和CLI仍为4.0.0，4.1安装包由M3准备。

## 技术方向与当前结果

将M1的真实位连接结果直接投影成局部电路，形成“源码→局部图→连续追踪→源码”的流程。复用原有Yosys/Slang、模型、ELK、SVG和图片导出；大模块的追踪入口不依赖先生成全模块布局。

源码通过编译快照、声明作用域、工具模块位置、实际网络和实际实例路径联合确认。Slang可能不给每条网络保留声明位置，因此缺少单条位置时需要所有其余证据成立；无法证明的情况明确提示改在电路中选择实际引脚。相关排查见[来源身份记录](bugs/logic-circuit-source-trace-identity.md)。

## 使用方式

1. 在RTL信号标识符上右键执行“追踪信号驱动”或“追踪信号负载”。十进制静态位/切片保留HDL原下标；动态索引要求输入具体位范围。
2. 同一源码模块存在多个实际实例时，选择对应实例。已配置`svtools.circuit.top`时保留该设计上下文；未配置则以所选声明的模块作为顶层。
3. 在电路中选择引脚、接口或网络，再使用详情面板的驱动/负载按钮。位范围输入`*`表示当前选择，也可输入`7:4`或单个HDL下标。工具栏“追踪信号…”从当前模块的实际网络中检索起点。
4. 上方边界按钮按分支展开，寄存器需点击“跨时序展开”；已知时钟、复位及使能说明保留在详情和按钮提示中。没有明确跨层端口映射时保持模块边界。
5. 点击已展开分支的“收起×”移除它及其后代；追踪后退/前进或`Alt+←/→`恢复分支、关注对象和相机。固定关注是标记对象，不固定节点坐标。
6. “查看源码”仅使用模型或经过验证的声明位置。编辑后提示当前图属于生成快照；刷新会重新生成，保持原始声明/位选择并清空旧历史。未保存正文使用任务快照，不改磁盘RTL。

连续展开保留相机倍率和起点的屏幕锚点，并标出新增节点。其他节点会受ELK重新布局影响；不保证每个节点原坐标不动。搜索高亮在展开及历史恢复时不抢占相机。

## 模块职责

| 文件 | 职责 |
|---|---|
| `trace-source.js` | 词法作用域、声明身份、静态位选择、真实网络/实例候选 |
| `source-snapshots.js` | 生成前内容身份、生成后验证、有界声明定位缓存 |
| `source-watch.js` | 当前设计已打开源码的编辑提示和监听释放 |
| `trace-projection.js` | 查询合并、端口位置裁剪、局部别名及常量隔离 |
| `trace-view.js` | 可信边界重放、ELK、连续布局锚点和取消 |
| `trace-controller.js` | 动作协议、历史、分支收起、上下文选择与操作世代 |
| `trace-actions.js` / `trace-client.js` | 原始对象映射、页面控件及消息适配 |

领域模型不写入坐标或展开状态；只在投影副本中为常量生成独立展示位。页面发送对象ID和边界令牌，源码路径与内容身份由宿主持有。

## 容量与失败行为

保留M1和4.0预算。局部视图最多512个真实单元、16,384个选中端口位位置和15个展开分支；导航历史最多32项，关注对象最多64个。扩展超过合并预算或布局失败时保留已有图并提示；M1查询自身的容量截断仍展示已发现结果和截断原因。

源码指纹最多64MiB、单文件16MiB、4,096个输入文件；声明回查单文件最多2MiB，缓存最多4个解析文档。实例候选至多256个，遍历队列至多4,096项、路径64级；不完整枚举标明截断并要求从层级入口缩小上下文。

取消使正在执行的异步布局失效，迟到响应不得覆盖当前页面。刷新、重载同一JSON和关闭也会使旧世代/旧边界失效。取消不承诺立即中断ELK内部计算，关闭会终止Worker。

## 验收与测量

- 完整回归：golden44/44；既有Node675通过、12项环境可选跳过；另指定本机Qoder的TextMate/Oniguruma复验高亮4/4，其中补验了原先跳过的一项。无测试失败。
- 最终电路回归214/214，包含真实内置Slang/Yosys、原有4.0页面行为、独立局部投影、作用域/遮蔽、实例端口位映射、常量隔离、历史、取消和过期世代。JS语法223文件；公开打包清单469文件、107,031,475 bytes，私有目录与入口均排除，公开命令49项。
- 真实Qoder API1.106.3和VS Code1.143.0各6项通过：源码`q[2]`直接进入、显式跨时序/组合展开、历史收起、验证源码跳转、脏正文刷新与旧位置拒绝，以及负载命令。
- 3,000单元Worker回归证明全模块布局超预算后，选定位仍可完成局部ELK，不仅能查询。
- 新基准固定20,000个独立反相器、5次冷会话、5次预热和20次热布局，计入真实Worker往返、索引、查询、投影及ELK。预设冷P95≤2,000ms、热P95≤1,000ms；本机Node24.17.0/Windows x64观测冷约422ms、热约45ms、加载P95约308ms。局部结果为1单元、3节点、2连线且无截断；完整布局明确超出既有引脚预算。

基准使用明确标记的合成JSON，不冒充Yosys工具输出；不包含工具生成、源码解析、SVG首绘或鼠标帧率。复验：`node scripts/benchmark-circuit-trace-view.js`，完整数据在`bin/circuit-trace-view-benchmark/report.json`。

本轮Windows浏览器自动化因不能可靠确认当前URL被运行时停止，实际明暗主题及鼠标视觉复验尚未完成。Qoder/VS Code的验收通过扩展测试宿主驱动真实命令、Worker及模型，不替代人工视觉验收。M3需要完成该项，并对正式安装包解包复验。

## 已知限制与下一阶段

- 层级成员表达式、结构体成员、task/function局部、匿名块局部或无法证明的generate索引路径，不回退到同名模块信号；请从真实电路引脚追踪。
- 条件编译声明缺少单条工具位置时拒绝源码起点；宏上下文、工具优化掉的网络或缺少模块源位置可能无法从源码进入。
- 外部导入JSON以及当前未采集工程全部快照的Vivado工程视图仍可按模型追踪；没有可验证源码身份时禁用局部图的源码跳转。Vivado当前文件入口只采集所选文件快照。
- 编辑提示覆盖本次生成使用的已打开正文；磁盘外部改动会在跳转时重新校验。include文件未单独纳入快照时不宣称可验证定位。
- 不持久化跨IDE重启的追踪历史；刷新重新生成起点，面板内前进返回恢复展开和相机。波形映射和值叠加属于M4。
