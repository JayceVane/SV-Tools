# 电路与 VCD 双向定位

本页描述 4.1 开发分支的波形联动功能；已发布安装包以各自版本说明为准。

## 开始关联

1. 打开需要分析的电路图和仿真结束后的 VCD。
2. 在电路工具栏点击“关联波形…”，或在波形工具栏点击“关联电路…”。
3. 有多个视图时选择要配对的对象，再明确选择 VCD 中对应电路顶层的 DUT 根实例。例如电路顶层 `chip` 对应 `tb.dut`。

这是人工确认的层级对应。界面会显示双方关系，并保留“未验证同次构建”的提示。
即便信号名称与位宽相同，也不能证明网表和波形来自相同的参数、宏或源码。

## 双向定位

- 在电路中选择端口、引脚或网络，点击“添加到波形…”；也可右键操作。
- 有多个命名网络或实际实例时选择准确的上下文。仅添加尚未显示的波形，已有行直接定位。
- 电路的“追踪位 / 范围”字段也用于波形定位。`6:5` 等切片会映射到真实 VCD 声明，必要时显示逐位行；保留原时间视窗。
- 在波形行上右键，选择“电路追踪 → 在电路追踪驱动 / 负载”。逐位行只追踪该 HDL 下标，重复模块按实际实例处理。
- 反向追踪使用已有电路数据，不重新生成电路。继续沿用局部逻辑锥、历史导航和源码定位。

## 映射失效

电路刷新、源码变化、视图关闭或重新仿真都会使相关映射失效。重新打开 VCD 后需再次确认根实例。
外部工具改写了打开的 VCD 时，也必须关闭并重新打开，不能沿用旧 identifier code 或压缩事件。
取消选择不会提交新映射，迟到的旧设计或旧视图请求不会覆盖当前操作。

## 当前边界

- 关联对象是工具保留的真实命名网络。常量引脚不能按相同常量值反推成任意信号。
- 层级、名称、位宽、方向和 HDL 下标需要匹配。不同参数、未 dump、被优化删除或缺少声明范围时不猜测。
- VCD 可以记录原声明的完整向量或已选择切片；本阶段不自动拼合多个不完整 dump 声明。
- 保留真实作用域分段，带点的转义标识符与多个嵌套实例不会混为一谈。Yosys没有提供可验证结构的扁平名称不会按点号自动拆分。
- Vivado沿用适配器已有的平坦限定名称，不假造缺失的模块层级。
- 单次关联最多 4096 位，显示最多 2000 行；映射索引最多 100000 条 VCD 声明及作用域。超过预算会提示，原波形查看仍可使用。
- 映射仅在当前会话有效。本阶段提供双向定位；电路上的 A 游标值及 A/B 差异属于后续阶段。
