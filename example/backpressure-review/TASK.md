# 背压保持复核题面

在生成的工作区打开「SV Tools: 打开设计讲解」。先阅读规则、激励和预期，分别写下两次运行应接收的字节、保持检查的触发前提和预期执行次数，再查看实际结果。

1. 两次运行的接收结果相同，分别能支持哪些接口结论？为每条结论写下日志或波形依据。
2. 保持检查在哪一拍执行？为什么恢复 `ready` 的那一拍也要比较？
3. 给出一项需要额外激励才能核对的行为，并写下对应的触发前提。

对照验收时，在同一组采样材料中分别走原始源码、日志和波形路径，以及 4.3 设计讲解路径。先记录预期，答完再核对。两轮换题并交换入口顺序，记录推导耗时、证据定位耗时、操作数、答对项和误放行项。
